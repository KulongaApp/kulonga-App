# UX — selecção de província

A selecção antiga usava emojis regionais dentro de uma grelha de cartões. Isso criava uma aparência inconsistente entre plataformas, dificultava a leitura rápida e ocupava demasiado espaço em ecrãs largos.

O novo padrão usa uma lista pesquisável, ordenada alfabeticamente, com ícones vectoriais consistentes, nome, contexto (“Província de Angola”), estado seleccionado com radio/check e contador de resultados. Em desktop a lista usa duas colunas; em ecrãs pequenos usa uma coluna. A acção de continuar permanece fixa no rodapé e mostra claramente a escolha actual.

Esta decisão segue padrões comuns de pesquisa móvel: a pesquisa deve ser visível quando a lista pode ser filtrada, os resultados devem actualizar enquanto o utilizador escreve e a selecção deve fornecer feedback imediato. [1] Para listas de localização, uma lista textual pesquisável e ordenada é mais previsível do que depender de mapas ou ilustrações, e a detecção automática deve continuar a ser apenas uma sugestão, não uma imposição.
